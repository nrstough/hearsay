## Problem

NSA's submission requires a Docker image that "executes inference on the provided test set without major configuration changes". Nothing exists: no `Dockerfile`, no `.dockerignore`, no `docker/`, and no end-to-end runner. Only M1 goes from audio to TSV today (`scripts/make_probe_csv.py`), and it writes into `submissions/` and appends `submissions/log.csv`, which is wrong inside a container. The image must reproduce the logged M1b v3 TSV (`submissions/20260926-0522_M1_m1_wav2vec2-xls-r-300m_L7_20260926-0521.tsv`, holdout minDCF 0.0717, EER 0.014, In-the-Wild minDCF 0.342) on CPU, on amd64, with no network, and be ready to take the fusion rule the main chat freezes at 22:00 without a redesign.

Three facts found during P1/P2 shape the design:
1. The shipped probe's `segment` flag is wrong. `scripts/train_probe.py:81` builds the metadata path from the comma-joined train name `nsa_train_sample_v3,asv19_addon_v3`, which does not exist, so `probe.segment` silently stays `False` (the 0518 probe, one train set, reads `True`). The logged TSV is correct because `scripts/tsv_from_embeddings.py` used precomputed segment-mode embeddings. The runner therefore never trusts the flag (D5).
2. The lockfile's torch 2.14.0 pulls CUDA on Linux: `cuda-toolkit`, `nvidia-cudnn-cu13`, `triton` and 43 `nvidia-*` packages under `sys_platform == 'linux'` markers. The image must install the CPU pair from the PyTorch CPU index and keep every other locked version, because the probe is a joblib pickle of a scikit-learn 1.9.1 pipeline (D1).
3. `models/hc_selected` is a symlink the D-track chat retargets (05:54: `hc_lgbm_20260926-055451`, v5). The build resolves it at build time and records what shipped (D3).

## Decisions

- **D1 Dependencies from the lock, CPU torch.** Base `python:3.12-slim-bookworm`; `apt-get install --no-install-recommends ffmpeg` in one cleaned layer. Requirements are exported at build time from `uv.lock` (`uv export --frozen --no-dev --no-hashes --no-emit-project --no-emit-package torch --no-emit-package torchaudio --no-emit-package lightgbm`), filtered of lines starting with `nvidia-`, `cuda-` and `triton`, and installed into `/opt/venv`; then `torch==2.14.0` and `torchaudio==2.11.0` from `https://download.pytorch.org/whl/cpu`. `lightgbm` is never installed (architecture invariant 7). `src/hearsay` is installed editable (`--no-deps -e .`); `PYTHONPATH=/app/src` is the fallback if the build backend is unavailable. The exact RUN block is fixed by the toolchain probe in the plan.
- **D2 Offline.** `ENV HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 HF_HUB_DISABLE_TELEMETRY=1`. The entrypoint passes `--require-offline`, so a container started without those variables refuses to run. Every image check runs with `--network none`.
- **D3 Shipped assets and identity.** `COPY` `weights/wav2vec2-xls-r-300m` and `weights/Spectra-AASIST` to `/app/weights/<same name>` (the paths `hearsay.embed.load_backbone` and `hearsay.spectra.WEIGHTS` derive from `REPO`); `weights/spkrec-ecapa-voxceleb` (85 MB) likewise, because the runner registers speaker drift as evidence; the shipped bundles are staged by `docker/build.sh` into `docker/build/models/` with symlinks resolved and copied to `/app/models/`: the probe under its real name (`hearsay.pipeline.PROBE_DIR`), `hc_selected`, `cmp_selected` (the compression detector's bundle) and `fusion_v0/constants.json` (as amended 06:35). `docker/build.sh` resolves `PROBE_DIR` and `HC_DIR` with `readlink -f` into build args and writes `/app/BUILD_INFO` (git sha, dirty flag, stamp, probe dir, hc dir). `docker/assets.py freeze` writes `/app/assets.json` (sha256 and size of every shipped model file and of the backbone weight files); the runner verifies it at startup. `.dockerignore` excludes `.git`, `.venv`, `data/`, `outputs/`, `submissions/`, `.cache`, `weights/wavlm-*`, audio files, caches.
- **D4 The runner, `scripts/run_pipeline.py`.** Also runs on the Mac (that is how Mac-side parity is measured). CLI: `--data DIR --out DIR [--template TSV] [--team NAME] [--detectors m1b|m1b,spectra,handcrafted] [--fusion bundle.json] [--policy speech_gate|none] [--limit N] [--device cpu] [--m1-mode segment|windows|auto] [--no-truncate] [--require-offline] [--app-root DIR]`; environment `HEARSAY_TEAM`, `HEARSAY_DETECTORS`, `HEARSAY_TEMPLATE`, `HEARSAY_FUSION`, `HEARSAY_POLICY`, `OMP_NUM_THREADS`. Flow: environment checks (offline, ffmpeg on PATH, threads) → list files (D4a) → asset verification → per detector, in order: load, preflight (silence and chord through that detector, finite and reproducible, values recorded), score every file not in the cache with `score_files` semantics, append to the cache, unload before the next → fusion (D8) → speech-gate policy (D9) → TSV (D10) → sidecar → summary → exit.
  - **D4a Listing.** With a template: read it as tab-separated (`filename` column), resolve each name by basename against a recursive index of `/data` (nested layouts work; duplicate basenames in different directories fail as ambiguous), keep template order, and keep a row for a name that is absent from `/data` (fallback score, flag `missing_file`, warning). Without a template: `hearsay.submission.list_test_files` (sorted recursive listing of `AUDIO_EXT`). Duplicate template names fail before scoring. An empty listing fails with no TSV. `--limit N` keeps the first N rows and suffixes the output name with `-limitN`. Each file's sha256 is computed at listing time for the cache key.
- **D5 M1 scoring.** `load_backbone(probe.backbone, "cpu")` → `truncate_backbone(model, probe.layer)` keeps `encoder.layers[:layer+1]` (verified bit-identical for `hidden_states[layer]` under transformers 5.17, which does not tie the last hidden state for Wav2Vec2; keeping `layer+1` is also correct under the v4 semantics) → per file `prepare_segment(x)` then `embed_segment(model, ·)` → cached logit `probe.llr(e)[0]` (prior-neutral LLR, the same quantity `scripts/export_probe_scores.py` exports) → posterior `sigmoid(llr + log(π/(1−π)))`, π = 0.3, no cost shift (identical to `scripts/make_probe_csv.py:55-67`). Fallback score is the prior-only posterior, 0.3. `--m1-mode` defaults to `segment`; a probe whose flag disagrees prints a warning; only `auto` follows the flag. `torch.manual_seed(0)`; threads from `OMP_NUM_THREADS`, default all cores.
- **D6 Spectra scoring** (shipped, not in the default detector list until fusion says so). `hearsay.spectra.load_spectra("cpu")`; per file `prepare_input(x)` (band match, no crop) → `score_clip(model, x, ("zero",), 16)` → logit `synth_logit(out["zero"])`, score `sigmoid(logit)`; peak normalisation off. These are the settings of the published export (`outputs/detector_scores/spectra_aasist_summary.json`: pad_mode zero, peak_norm false); the constants live in one block and a test cross-checks them against that file when present.
- **D7 Handcrafted scoring** (shipped, same status). `HandcraftedDetector(model_dir=<app>/models/hc_selected)` through `safe_run(det, ClipContext(path))`; logit is the `hc_logit` feature, `log(p/(1−p))` with p clipped at 1e-6, the same as `scripts/train_handcrafted.py:decision`; a non-`ok` result gives the fallback plus a flag.
- **D8 Fusion bundle.** A JSON file `{"detectors": [...], "standardize": {name: {"mu", "sd"}}, "rule": "identity" | "zmean" | {"type": "linear", "weights": {name: w}, "intercept": b}, "platt": [a, b], "pi_synth": 0.3, "source": "..."}`. `apply_fusion` standardises each detector's logit with its inner-OOF mean and sd, applies the rule, then `p = sigmoid(a·fused + b + log(π/(1−π)))`, which is the arithmetic of `scripts/fuse.py` (standardisation, `zmean`, `stack_nonlj`, the Platt map and prior shift). With no bundle the rule is identity on M1b, and the output equals D5 exactly. A file missing any detector logit under a bundle gets the fallback plus `fusion_missing:<det>`; a bundle naming a detector the runner cannot produce fails before scoring. This is the contract for `fuse.py --write` to fill.
- **D9 Speech-gate policy** (handoff, 06:15). The runner runs `hearsay.detectors.speech_gate` per file as a cheap CPU pass, records `is_speech` and the reasons in the sidecar, and applies `apply_default_answer(fused, is_speech)` after fusion: gated files get 0.02 plus 1e-4 times their fused score. A decode failure is gated the same way (is_speech false). Default `--policy speech_gate`; `none` disables it for parity against the logged M1 TSV, which predates the gate. The preflight silence and chord therefore land near 0.02 in the final scores; the per-detector preflight values are still recorded raw.
- **D10 Output.** `write_submission` to `/out/<TEAM>_predictions.tsv` (`HEARSAY_TEAM`, placeholder `teamName`); if it exists, `<TEAM>_predictions-<stamp>.tsv`; never overwrite, never `append_log` inside the container (log.csv is a repo artifact; Nathan logs a container TSV on the Mac once parity passes). Beside it, `<stem>.sidecar.csv` (per file: id, score, flag, per-detector logits, is_speech) and `<stem>.run.json` (git sha and dirty flag, BUILD_INFO, library versions, ffmpeg banner, asset hashes, detectors, fusion rule, policy, truncation depth, preflight values, wall time per detector, flag counts, share above 0.5, `partial` for `--limit`). Scores outside [0, 1] are caught at scoring time (fallback, flag `out_of_range`), never clipped. Exit code 0 whenever a TSV was written, even with flagged rows; non-zero only when none was.
- **D11 Cache.** `/out/cache/<detector>.jsonl`: a header line `{manifest_sha, config_sha, detector, created}` then one line per file `{id, sha256, logit, score, flag, seconds}`. A different manifest hash (file set and content) or config hash (probe sha, truncation, mode, pad mode, bundle) discards the cache with a notice; a corrupt trailing line is skipped and rescored; rows are looked up by id and sha256.
- **D12 docker/ scripts** (as amended 06:35). `entrypoint.sh` (`set -euo pipefail`; threads from the cgroup quota into `OMP_NUM_THREADS`/`MKL_NUM_THREADS`; a lone `/data/*.tsv` becomes `HEARSAY_TEMPLATE`; `assets.py verify` before anything runs; then `exec python scripts/run_pipeline.py --in /data --out /out --threads N "$@"`); `build.sh` (`docker buildx build --platform linux/amd64 --load`, build args, tags `hearsay:<stamp>` and `hearsay:latest`, `BUILD_INFO`); `smoke.sh` (3 files: WAV, MP3, FLAC; reversed template; `--network none`; row count and order check; run twice for determinism; a second pass with all three detectors); `parity.py` (`pcm-hash` / `pcm-diff`: decoded-PCM hashes via `scripts/hash_audio.hash_one`; score parity is the runner's own `--compare-tsv`); `assets.py` (`freeze`, `verify`).
- **D13 Tests are hermetic** (as amended 06:35). `tests/test_docker_image.py`: B1–B10 on the Dockerfile, `.dockerignore`, the scripts, the staging resolution and the asset manifest, P2–P4 on `parity.py`, `smoke.sh` and `build.sh`, plus a static check that the entrypoint's flags exist in the main chat's runner. The runner's own tests are the main chat's. Image checks are the scripts in D12, run by hand and recorded below.
- **D14 Out of scope for this rung.** M5 in the image; running speaker drift in the pipeline (weights and dependency ship, the detector is evidence only); the explanation report; registry push or tarball; the Sunday rebuild (a separate execution that drops in the fusion bundle and rebuilds).

1. `scripts/train_probe.py:81`: split `args.train` on commas and read the first set's `extract_meta.json` (or assert all agree), so `probe.segment` is right for multi-set probes. `hearsay.pipeline` already ignores the flag.

4. `read_template_ids` accepts a comma template when no tab is on the header line; NSA's file is tab-separated, so a tab-only parse would fail loudly on the wrong file instead of reading a comma file's first column.
