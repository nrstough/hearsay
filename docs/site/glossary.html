Glossary

Every term that carries a tooltip on this site, defined once.

ASVspoof 2019 (also: ASVspoof)
A public anti-spoofing benchmark. Its real speakers and a small set of its attacks were added to the training folds only, never to the holdout.
AUC
Area under the ROC curve: the probability that a random synthetic file scores above a random real one. 1.0 is perfect separation, 0.5 is chance.
band match (also: band-matched, band-matching, Kaiser low-pass)
A low-pass filter applied to every clip, training and test alike, so that the test set's roll-off above about 7 kHz is no longer a fingerprint that separates test audio from training audio.
Bayes threshold (also: operating threshold)
The score at which calling a file synthetic starts to pay under the cost weights and the prior. With a false alarm this expensive it sits far above 0.5 on the probability scale, which is why "above 0.5" is not the decision rule.
compression forensics (also: compression, codec traces)
Features that read the traces a lossy codec leaves in the upper band: spectral holes, floor depth, effective bandwidth. They describe a file's processing history, not the voice, so they are evidence and routing here.
container (also: metadata, header facts)
What the file header says: codec, sample rate, bit depth, encoder tags. Read for routing; never learned from, because on our training data the container is the label.
DiffSSD
The sponsor's synthetic training corpus: clips from ten text-to-speech generators, including commercial ones.
draft review (also: one-time draft review)
The sponsor's one-time offer to score an early submission and return its minDCF. We sent the exact file we ship and decided in advance what each returned value would mean.
ECAPA (also: ECAPA-TDNN, speaker embedding)
A pretrained speaker-recognition network that turns a second of speech into a vector describing the voice. Comparing vectors from successive windows shows whether the voice stays the same within a clip.
EER (also: equal error rate)
Equal error rate: the point on the threshold sweep where the false-alarm rate equals the miss rate. Reported alongside minDCF, never selected on.
ENF (also: mains hum, electrical network frequency)
Electrical network frequency: the faint 50 or 60 Hz hum a mains-powered recording chain leaves in a recording, and how stable it is. Evidence about the recording environment.
evidence (also: evidence only)
A detector result that is reported in the explanation for a file but never enters the score. Four detectors are evidence-only because what they measure is real, but on this test set it does not separate real from synthetic.
explanation JSON (also: routing log, per-file report)
The record the runner writes for each file: every detector's score, status and one-sentence evidence, the fusion inputs, and the routing log of what each rule decided.
false alarm (also: P_FA, false-alarm rate)
A real recording that the system calls synthetic. P_FA is the share of real files scored above the threshold. This is the expensive mistake under the sponsor's cost.
generator (also: TTS generator, vocoder)
A text-to-speech or voice-cloning system that produced synthetic clips. Folds hold out whole generators so that every readout is on synthetic speech from a system the model never saw.
gradient-boosted trees (also: LightGBM, trees)
An ensemble of small decision trees trained one after another. LightGBM trains them; at inference the dumped trees are evaluated in numpy so that the training library is never imported.
handcrafted detector (also: handcrafted, spectral + prosody)
Engineered spectral and prosody features (cepstral statistics, spectral shape, phase cues, pitch, loudness, pauses) fed to gradient-boosted trees, evaluated at inference in plain numpy.
holdout (also: outer holdout)
A slice of the training data that no model was ever fitted, tuned or selected on: two generators and a set of real-speech groups. Each model reads it once. With only two held-out generators it is noisy, so small differences on it are not evidence.
In-the-Wild (also: ITW)
A public set of web-sourced real and fake speech, used only as a stress test for false alarms on unfamiliar real voices. Nothing was ever trained on it.
inner folds (also: inner fold)
The five training folds. Each holds out whole generators, so a model is always tested on synthetic speech from a system it never trained on. Scalers, calibration and fusion weights are fitted inside each fold as well.
laundering (also: laundered, laundering augmentation)
Passing audio through a codec round-trip, band-limit or added noise. Attackers do it to hide artifacts; we do it to both classes in training so a detector cannot learn "compressed means fake".
LibriSpeech
A public multi-speaker read-speech corpus. The multi-speaker real side of the training data.
LJ Speech (also: LJ)
A public read-speech corpus of a single speaker. Part of the real side of the training data; being one voice, it is a shortcut risk of its own.
LLR (also: log-likelihood ratio, calibrated log-likelihood ratio)
Log-likelihood ratio: the log of how much more likely the evidence is under "synthetic" than under "real". Positive means synthetic-like, negative real-like, zero is even. The XLS-R probe reports one per file.
M1b (also: M1, the probe, XLS-R probe)
Our primary detector: a frozen XLS-R with a small logistic classifier on one hidden layer. M1b is the version whose training folds also include a set of extra real speakers.
M5 (also: fine-tuned head, M5 head)
A trained head on a truncated XLS-R: learned layer weights, attentive pooling and a linear output, trained on rented GPUs with heavy augmentation. It did not beat the plain probe on its own and ships as a minority vote in the fusion.
minDCF (also: minimum detection cost, normalized minDCF)
Minimum detection cost function. The scorer sweeps every possible threshold over our scores and reports the lowest cost it finds, with a false alarm weighted far more than a miss and the whole thing scaled so that 1.0 equals the best constant answer and 0.0 is perfect. Because the threshold is chosen by the scorer, only the order of our scores matters.
miss (also: P_miss, miss rate)
A synthetic recording that the system calls real. P_miss is the share of synthetic files scored below the threshold. The cheap mistake, relatively speaking.
MLAAD
A public multi-generator synthetic-speech set. Its English clips were training-only data for the M5 model and a miss-rate readout on unseen generators for the others.
out-of-fold (also: OOF, inner out-of-fold, inner OOF)
A score a model gives to a training row it never saw: the training data is split into folds, and each row is scored by the model fitted on the other folds. Every selection decision in this project uses out-of-fold scores.
pinned block (also: default answer, abstention, default-answer policy)
Files the system cannot judge (no speech, or a failed decode) are placed strictly below every judged file, at the real end of the ranking, in a deterministic order. Under the sponsor's cost, an uncertain file belongs there.
Platt map (also: Platt, Platt scaling)
A one-dimensional logistic fit that turns a raw decision value into a probability. It is monotone, so it changes the numbers a reader sees without changing the ranking the metric scores.
pre-declared (also: pre-declared sweep, selection rule)
Written down before any result was looked at: the candidates, the readouts, and the rule that picks a winner. Once the rule has been applied there is no second try.
prosody
The rhythm and melody of speech: pitch movement, loudness changes, pauses, breaths. Synthetic speech tends to be more regular than a person.
rank blend (also: rank fusion, rank space)
Each detector's raw score is replaced by its rank among that detector's own out-of-fold training scores (the share of training rows scoring below it), and the ranks are combined with fixed weights. Ranking is all the metric sees, so fusing ranks avoids letting one detector's scale dominate.
router (also: orchestrator, orchestration, routing)
The fixed rules that decide what each detector's result is allowed to do for a given file: fused into the score, allowed only to lower it, or recorded as evidence. Every decision is written to a per-file routing log.
shortcut (also: shortcuts)
A difference between training and test data that a model can exploit instead of listening to the voice: peak level, leading silence, clip length, container fields, a missing high band. Each one found was closed before it could be learned.
Spectra-AASIST (also: M3, Spectra)
An off-the-shelf anti-spoofing model run without any training. It is the strongest detector on every set we hold, but its training data is undisclosed, so it is allowed only to lower scores, never to raise them.
spectral (also: spectral features)
Features of the frequency content of the audio over time: energy per band, roll-off, flatness, cepstral coefficients (MFCC, LFCC, CQCC) and how they change from frame to frame.
speech gate (also: gate, non-speech gate)
Five cheap cues that decide whether a file contains speech at all (not silent, some voiced frames, pitch that moves, loudness that moves, not spectrally flat). A file that fails goes to the pinned block instead of fusion.
splice (also: editing seam, seam)
A discontinuity where audio was cut or inserted: a single-sample click or a jump in the DC offset between windows. Evidence of editing, though on this data it mostly finds vocoder artifacts.
sponsor code (also: sponsor-code reading, miss-averse cost, sponsor's scoring code)
The evaluation script the sponsor shipped. It reads a higher score as real, the opposite of the instructions, and puts the heavier weight on a missed fake. We report every result under both readings and never flip our scores.
suppression (also: suppressor, false-alarm suppression)
The one-way role given to Spectra-AASIST: when it is confident a voice is real and the fused rank is high, the rank is halved. It can never raise a score, so if it is wrong the cost is a miss, never a false alarm.
test share (also: share above 0.5, test share above 0.5)
The fraction of the test files scored above 0.5, watched against the roughly 30% synthetic the brief states. A smoke alarm for a broken model, never a selection signal, because any monotone rescaling changes it without changing minDCF.
TSV (also: prediction file)
The tab-separated submission: a header line, then one row per test file with the filename and the probability that it is synthetic, in the sponsor's template order.
XLS-R (also: wav2vec2-xls-r-300m, XLS-R 300M)
A large self-supervised speech model from Meta, pretrained on many languages and never trained for spoof detection. Its middle layers carry the acoustic detail that separates vocoders from voices; we read one of those layers.
