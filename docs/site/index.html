PROJECT
OVERVIEW

PROBLEM

A convincing synthetic voice can sound real. Calling real speech synthetic is the expensive error in this challenge.

SOLUTION

One decode path, ten forensic detectors, a fixed router, and an explained probability for every file.

MEASURED RESULTS

0.0065 holdout · 0.228 In-the-Wild normalized minDCF.

PROJECT OVERVIEW

Give HEARSAY an audio file. It returns a score, the evidence behind it, and a record of how the decision was made.

THE OUTPUT

A submission TSV and one explanation JSON per file.

THE PRINCIPLE

Every detector runs; the router decides which findings may affect the score.

SCOPE

CORE SYSTEM

  • Decode audio once to a shared format
  • Run ten detectors behind one contract
  • Fuse M1b, handcrafted, and M5 by rank
  • Let Spectra only lower a likely false alarm
  • Write a score and evidence report

OUT OF SCOPE

  • No hardware signal or device attestation
  • No hosted model on the scoring path
  • No retraining during inference

THE LESSONS / 01–04

WHAT WE LEARNED

01 / 02
  1. 01

    Our test data lied to us, five times.

    Real and fake clips differed in volume, silence at the start, length, file format, and a filter cutoff at 7.2 kHz. A model could “win” on any of those without hearing the voice. We found each one and removed it. Next time we check for this on day one.

  2. 02

    Good scores at home don't mean good scores in the wild.

    Our best models scored around 0.1 on our own held-out data and around 0.4 on real-world recordings. The fusion rule that looked best at home was the worst in the wild. We only avoided shipping it because we wrote down the selection rule before seeing the numbers.

  3. 03

    Fix the data before adding more of it.

    Adding 40 real speakers made things worse until we matched our training audio to the test set's filter. Then the same speakers made things better.

  4. 04

    One false alarm costs 9 misses. Design for that.

    This one number shaped everything: a detector that can only lower a score, a model tuned for fewer false alarms, and unreadable files pinned to the bottom of the list.

Explore the evidence ↗

THE LESSONS / 05–08

WHAT WE LEARNED

02 / 02
  1. 05

    Half our detectors don't vote, and that's fine.

    Five of ten detectors turned out to detect the recording setup, not the voice. Mains hum means “recorded at home”. Compression means “went through a pipeline”. Those detectors now explain the answer instead of setting it.

  2. 06

    A weak model can still help.

    Our fine-tuned model lost to the simple one on every test. But it makes different mistakes, so giving it a small vote cut errors in half.

  3. 07

    If you can't check a model, limit what it can do.

    Spectra-AASIST scored perfectly on our data, but nobody knows what it was trained on. So it can only say “this is real”, never “this is fake”.

  4. 08

    Test for weaknesses before you freeze.

    We found that background noise breaks the shipped model after it was too late to fix.

The numbers

All figures are normalized minDCFMinimum detection cost function. The scorer sweeps every possible threshold over our scores and reports the lowest cost it finds, with a false alarm weighted far more than a miss and the whole thing scaled so that 1.0 equals the best constant answer and 0.0 is perfect. Because the threshold is chosen by the scorer, only the order of our scores matters. (lower is better). The rule was chosen by a pre-declaredWritten down before any result was looked at: the candidates, the readouts, and the rule that picks a winner. Once the rule has been applied there is no second try. selection rule, applied once; the out-of-foldA score a model gives to a training row it never saw: the training data is split into folds, and each row is scored by the model fitted on the other folds. Every selection decision in this project uses out-of-fold scores. figure is the training-side readout, the holdoutA slice of the training data that no model was ever fitted, tuned or selected on: two generators and a set of real-speech groups. Each model reads it once. With only two held-out generators it is noisy, so small differences on it are not evidence. and In-the-WildA public set of web-sourced real and fake speech, used only as a stress test for false alarms on unfamiliar real voices. Nothing was ever trained on it. figures were each read once after the choice.

The cost function we are judged on

minDCF = 9.33 × PFA + 1 × Pmiss

One real file called synthetic costs as much as 9.33 missed fakes. That single ratio shaped every decision in this system.

PFA
false-alarm rate: the share of real files scored above the threshold
Pmiss
miss rate: the share of synthetic files scored below it
min
the best threshold is chosen by the scorer, so only the ranking of scores matters

Built from the sponsor's weights CFA = 4, Cmiss = 1 and a prior of 0.3 synthetic (about 0.7 of files are real): cost = 4 · PFA · 0.7 + 1 · Pmiss · 0.3 = 2.8 · PFA + 0.3 · Pmiss, divided by the best constant decision, 0.3, so that 1.0 means "no better than always saying real" and 0.0 is perfect. source: src/hearsay/metrics.py lines 29-31 (GitHub; assumes main is public)

How it decides, in one picture

One decode path, ten detectors behind one contract, a router that tells each result what it may do, and a fusion rule that reads only ranks: 0.6 × rank(M1b) + 0.2 × rank(handcrafted) + 0.2 × rank(M5), then Spectra-AASISTAn off-the-shelf anti-spoofing model run without any training. It is the strongest detector on every set we hold, but its training data is undisclosed, so it is allowed only to lower scores, never to raise them. allowed only to pull a file toward real, then a Platt mapA one-dimensional logistic fit that turns a raw decision value into a probability. It is monotone, so it changes the numbers a reader sees without changing the ranking the metric scores., with undecidable files in the pinned blockFiles the system cannot judge (no speech, or a failed decode) are placed strictly below every judged file, at the real end of the ranking, in a deterministic order. Under the sponsor's cost, an uncertain file belongs there. at the real end. The full walk-through, with a real test file, is on How it decides.
