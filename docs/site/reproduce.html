Reproduce it

Setup

Requires uv and FFmpeg. Source: the README's setup section.

uv sync
cp .env.example .env
uv run pytest -q
uv run ruff check .

Data, weights, model directories and submission TSVs are gitignored; only the experiment log is tracked. Expected layout: the NSA test set at data/nsa/HackGTHearsayTesting/, the template at data/nsa/HearsayScoreKey4TeamX.tsv, pretrained weights under weights/, trained bundles under models/.

Score a directory

uv run python scripts/run_pipeline.py --in data/nsa/HackGTHearsayTesting --out outputs/runner/final --template data/nsa/HearsayScoreKey4TeamX.tsv --team CrossExam --fusion models/fusion_v2/constants.json

--fusion models/fusion_v2/constants.json selects the shipped rule. It writes CrossExam_predictions.tsv, one explanation JSON per file under results/, a resumable results.jsonl, timings.csv and run_meta.json. Rerun the same command to resume after a crash. --flip also writes the pre-flipped twin; --rule, --policy and --flip re-fuse the cached logits without reloading a model. Reproduce in Docker (offline, CPU; not a graded deliverable)

NSA said on Saturday that the image is not required; the deliverable is the TSV and the README. The image is kept as evidence that the pipeline runs offline from a clean build. The recorded image runs the previous rule, not the shipped one: it does not contain the M5 checkpoint. Source: the README.

bash docker/build.sh
docker run --network none -v <test_dir>:/data:ro -v <out_dir>:/out -v <path>/HearsayScoreKey4TeamX.tsv:/tmpl/key.tsv:ro -e HEARSAY_TEMPLATE=/tmpl/key.tsv -e HEARSAY_TEAM=CrossExam hearsay:20260926-0916

The image contains every engineered detector, the M1b probe, Spectra-AASIST, the ECAPA speaker model, the handcrafted bundle and the fusion constants, with a sha manifest of the shipped files checked at start. It refuses to start unless it is offline, and nothing is downloaded at run time. Always pass HEARSAY_TEAM: the runner's default team name is not ours.
