Main commit: b8ce0db.

What it is

A self-contained HTML site under docs/site/, generated by scripts/build_site.py (Python standard library only) with its output committed, so nothing needs building to read it. It works opened from a checkout (docs/site/index.html), from python3 -m http.server in docs/site, and as a GitHub Pages site from main / docs once the repository is public. There is no runtime dependency: no CDN, no webfont, no library. Every number on a hand-written page carries a source link to the file and section it came from, and the build refuses a number it cannot find there.

Deviations from the plan, and why

  • Page metadata lives in a JSON comment at the top of each fragment instead of a separate pages.json; one place per page, same information.
  • The decision timeline is an HTML list with a source link per event, not a Mermaid diagram: more legible on a phone, and every time is cited.
  • The cost explorer's sliders and the inverted-index search were on the cut list; both were built.
  • All 26 spec pages were written; none was cut. The one page the plan listed as "explanation-json" and "runner-routing" are two pages, as planned; the spec index counts 27 because it includes itself.
  • A docs/.nojekyll file was proposed at the plan stop and not created: the site does not need it, and the file lies outside this lane's directory.
